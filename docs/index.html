Boulder Lens · concept prototype

Video feedback on bouldering technique

Below is a real report generated from a phone video filmed by hand at a climbing gym. The engine tracks the climber's body, compensates for the moving camera, and turns what it sees into feedback: strengths first, one thing to work on, clickable moments, measurements – and an honest list of what it could not judge.

Code & docs on GitHub · Lessons learned · Architecture

An interactive version – analyse your own video, privately, in the browser – is on the roadmap.
